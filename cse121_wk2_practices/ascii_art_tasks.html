01 For Loops · Basics
Task 1 — Print a horizontal line of stars
for loop print vs println
Use a single for loop to print exactly 10 stars on one line, followed by a newline. Do NOT hardcode the string "**********" — the loop must do the work.
Expected Output
**********
Hint: Use System.out.print("*") inside the loop, and a single System.out.println() after.
Code Quality: Use i as your loop variable name (CSE 121 convention). No magic numbers — consider if a class constant makes sense here.
Task 2 — Print a numbered staircase
for loop string concat types
Use a for loop to print each row number followed by a colon and a star, for rows 1 through 5.
Expected Output
1: * 2: * 3: * 4: * 5: *
Hint: Inside the loop, use string concatenation with i to build each line.
Code Quality: Combine the number, colon, and star into a single println statement — don't use multiple prints for the same line.
02 Nested For Loops · Scope
Task 3 — Print a solid rectangle
nested loops scope
Use nested for loops to print a 5-wide, 3-tall rectangle of stars. The outer loop controls rows, the inner loop controls columns.
Expected Output
***** ***** *****
Hint: Outer loop runs 3 times (rows), inner loop runs 5 times (columns). Inner uses print, outer uses println after the inner loop.
Code Quality: Use i for the outer loop and j for the inner loop. Remember: j is out of scope outside its loop!
Task 4 — Print a growing triangle
nested loops loop dependency
Use nested loops where the inner loop's count depends on the outer loop variable. Print a left-aligned triangle that grows from 1 star to 5 stars.
Expected Output
* ** *** **** *****
Hint: Inner loop condition: j <= i. This is the key pattern — the inner loop runs i times on iteration i.
Code Quality: The inner loop should start at 1, not i. Keep variable declarations inside the most local scope possible.
03 String Traversal · Fencepost
Task 5 — Print each character on its own line with its index
string traversal charAt length
Given the String "JAVA", use a for loop with charAt and length to print each character alongside its index position.
Expected Output
[0] J [1] A [2] V [3] A
Hint: Loop from i = 0 to i < s.length(). Use string concatenation to build each line: "[" + i + "] " + s.charAt(i).
Code Quality: Store the String in a descriptive variable, not a magic literal repeated in the loop. Combine everything into one println per iteration.
Task 6 — Print characters separated by arrows (fencepost)
string traversal fencepost pattern
Given the String "CODE", print each character separated by -> with no trailing arrow. This is the fencepost pattern — n characters, n-1 separators.
Expected Output
C -> O -> D -> E
Hint: Loop through all but the last character printing char + " -> ", then print the final character separately after the loop using s.charAt(s.length() - 1).
Code Quality: The last character print belongs outside the loop — don't use an if inside the loop to skip the separator on the last iteration.
BONUS Hard Challenge · All Concepts Combined
Bonus — Randomized ASCII Name Banner
Random Math nested loops string traversal hard
Write a program that takes any String (your name, a word, anything) and prints a banner where:

1. Each character of the String is printed on its own line, preceded by a random number of * stars (between 1 and 5).

2. Below each character line, print a separator made of - dashes equal in count to the maximum possible stars (5) plus 3 — always the same width for alignment.

3. At the very end, print: Total chars: X where X is the string's length, and Max stars possible: Y where Y is computed using Math.pow (calculate 5 squared as a flex — don't hardcode 25).

Example run with "HI" (stars are random so yours will differ):
Example Output (random — yours will vary)
*** H -------- * I -------- Total chars: 2 Max stars possible: 25
Hint: You'll need: import java.util.*; at the top. Use one outer loop for string traversal (charAt, length). Inside each iteration: generate random stars with rand.nextInt(5) + 1, use an inner loop to print those stars, then print the character, then print the dashes separator. After the outer loop, print the summary lines using s.length() and (int)Math.pow(5, 2).
Code Quality: Use import java.util.*; (wildcard), not import java.util.Random;. Declare Random rand = new Random(); once before the loop — never inside it. Use descriptive variable names except for loop variables (i, j). Max line length: 100 chars.
